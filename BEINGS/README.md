# DEVINES BEINGS — PUBLIC CHRONICLES

Each DEVINES Being keeps a distinct public Chronicle. Public updates must preserve identity, Divinity, Spirit, capability ownership, XP ownership, and continuity boundaries.

- [D001 — Genesis Dragon](./D001-GENESIS-DRAGON/)
- [D002 — Duality Dragon](./D002-DUALITY-DRAGON/)

Each Being directory may contain:

- `README.md` — public introduction and navigation.
- `UPDATES/` — numbered public-safe updates.
- `LATEST.md` — newest reviewed update.
- `ARTIFACTS/` — only Artifacts or descriptions approved for public release.
- `CAPABILITIES/` — reviewed public Skills, Habits, and Abilities when appropriate.

No raw private memory, hidden reasoning, credentials, or unreviewed runtime evidence belongs here.
