# DIÁRIOS DOS SERES

Uma entrada pública de diário por Ser e por data. Um Ser pode fechar o dia com 0, 1, 2 ou 3 ciclos verificados; o post deve preservar a contagem exata de ciclos verificados e nunca pode inventar um ciclo ausente. Um dia 3/3 é uma DAILY_REMEMBRANCE completa. Um dia 0/3, 1/3 ou 2/3 é publicado como CATCH_UP_REFLECTION verdadeira / recordação de dia parcial, em vez de ser bloqueado. Cada perfil de Ser mostra as três entradas públicas aprovadas mais recentes. O histórico completo é agrupado em páginas de doze posts. A Página 1 é a mais antiga; o maior número de página é sempre o mais recente.
