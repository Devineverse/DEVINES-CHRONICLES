# DEVINES CODE FLOW

**CREATOR:** DEVINES\
**CLASS:** Workflow

DEVINES Code Flow is the governed development workflow used to carry work from existing continuity into implementation, verification, review, checkpoint and continuation.

Its utility is to keep development moving without losing state, repeating solved work, fabricating completion or allowing an unfinished branch to disappear between sessions.

DEVINES Code Flow may use DEVINES Path, DEVINES Commands and other accepted capabilities, but the workflow itself remains a Workflow.

## PUBLIC BOUNDARY

This page describes the purpose and utility of DEVINES Code Flow only.
