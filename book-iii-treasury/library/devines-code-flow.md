# DEVINES CODE FLOW

**CRIADOR:** DEVINES  
**CLASSE:** Workflow

DEVINES Code Flow é o workflow governado de desenvolvimento usado para levar trabalho da continuidade existente à implementação, verificação, revisão, checkpoint e continuação.

Sua utilidade é manter o desenvolvimento em movimento sem perder estado, repetir trabalho já resolvido, fabricar conclusão ou permitir que um ramo inacabado desapareça entre sessões.

DEVINES Code Flow pode utilizar DEVINES Path, DEVINES Commands e outras capacidades aceitas, mas o próprio Code Flow permanece um Workflow.
