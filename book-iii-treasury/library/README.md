# DEVINES LIBRARY

A DEVINES Library foi concebida para se tornar um tesouro vivo de conhecimento ancestral.

Mitologia, filosofia, história, simbolismo, matemática, ciência, linguagem, sistemas naturais e tecnologia moderna podem se encontrar aqui — sem serem achatados em um único tipo de verdade.

A Library distingue aquilo que uma tradição afirma, o significado que um símbolo carregou, o que a evidência pode sustentar, o que permanece interpretação e como um Ser relaciona esse conhecimento ao próprio domínio.

O propósito não é acumular tudo. É preservar significado sem confundir significado com prova.

A Library também preserva criações DEVINES de acordo com sua verdadeira natureza.

**ARTEFATO != SKILL != ABILITY != WORKFLOW != MÉTODO != PROTOCOLO.**

Nem tudo que é importante é um Artefato.

A classificação vem antes da promoção.
