# Public Publishing Flow

> **Canonical event → sanitize → verify → Being voice → Public layer → Git → GitBook**

1. DEVINES produces a durable event.
2. A public projector reads only allow-listed fields.
3. Private memory, credentials, raw prompts/responses, hidden reasoning, exam keys and unsafe implementation detail are excluded.
4. The factual public event is frozen.
5. The Being Voice layer renders the same event using that Being's canonical identity, divinity and spirit.
6. A validator checks that every factual claim can be derived from the public event.
7. Markdown and machine-readable state are committed to this repository.
8. GitBook Git Sync publishes the same manuscript.

A voice layer may add **meaning and expression**. It may not add an event.
