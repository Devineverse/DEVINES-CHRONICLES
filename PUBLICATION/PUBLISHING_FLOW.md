# Fluxo de Publicação Pública

> **Evento canônico → sanitize → verify → voz do Being → camada Public → Git → GitBook**

1. DEVINES produz um evento durável.
2. Um public projector lê somente campos allow-listed.
3. Memória privada, credentials, raw prompts/responses, hidden reasoning, exam keys e detalhes inseguros de implementação são excluídos.
4. O evento factual público é congelado.
5. A camada Being Voice renderiza o mesmo evento usando a identidade, divinity e spirit canônicos daquele Being.
6. Um validator verifica que toda alegação factual pode ser derivada do evento público.
7. Markdown e estado machine-readable são commitados neste repositório.
8. GitBook Git Sync publica o mesmo manuscrito.

Uma voice layer pode acrescentar **significado e expressão**. Ela não pode acrescentar um evento.
