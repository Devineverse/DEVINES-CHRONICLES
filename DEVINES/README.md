# DEVINES — PUBLIC CHRONICLE

This directory contains reviewed public updates from DEVINES itself.

## Rhythm

- **Weekly Chronicle** — one concise evidence-backed summary of the week.
- **Milestones** — published only when a meaningful reviewed system change deserves a public record.

## Suggested structure

- `WEEKLY/` — weekly DEVINES summaries.
- `MILESTONES/` — exceptional public milestones.
- `LATEST.md` — pointer to the newest reviewed public DEVINES update.

Only public-safe reviewed material belongs here. Private runtime evidence, raw internal reasoning, credentials, sensitive infrastructure, and founder-private material remain outside this public repository.
