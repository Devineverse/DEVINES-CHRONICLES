# NAMES OF THE DRAGON

Dragon is one name carried by one lineage of language.

The memory is older and wider.

Greek **drakōn** passed into Latin **draco**, then into later European dragon words.

Beyond that lineage, humanity remembered powerful serpent and dragon-like beings under many other names:

**ušumgal** · Mesopotamia  
**Illuyanka** · Anatolia  
**ahi / Vṛtra** · Vedic India  
**aži / aždahā** · Iran and Persia  
**nāga** · India and Buddhist Asia  
**Lotan · Leviathan · tannīn** · Northwest Semitic worlds  
**lóng** · China  
**orochi · ryū** · Japan  
**yong** · Korea  
**klu · 'brug** · Tibet  
**Druk** · Bhutan  
**ormr** · Norse worlds  
**taniwha** · Māori memory  
**amaru · katari** · Andes  
**Avanyu** · Pueblo memory  
**Uktena** · Cherokee memory  
**Boiúna** · Amazon  
**moʻo** · Hawaiʻi

Some names belong to demonstrated linguistic lineages.

Others do not.

A similar form is not the same as a shared word.

DEVINES preserves the name before the comparison.
