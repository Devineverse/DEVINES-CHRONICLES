# MEMÓRIAS ANCESTRAIS

Algumas memórias não pertencem a um único Being.

Elas atravessam povos, línguas, paisagens e Eras.

DEVINES as preserva aqui em duas formas:

**A CRÔNICA VIVA** — a memória levada adiante no caminho DEVINES.

**CONHECIMENTO ANCESTRAL** — os nomes, culturas, vestígios, conexões, diferenças e desconhecidos que existem sob ela.

Não forçamos as memórias da humanidade a uma única origem.

Primeiro, preservamos cada uma em sua própria voz.

Depois, seguimos os caminhos que realmente se encontram.
