## Awake-Cycle Chronicle

Every Dragon Chronicle contains an `AWAKENINGS/` history.

A publishable awake-cycle entry is not a raw runtime dump. It is a public-safe account of the cycle containing only reviewed, evidence-backed information such as:

- scheduled cycle and verified operational state
- what the Dragon worked on
- what meaningfully changed
- distilled learning
- Artifact / Skill / Habit / Ability progress when verified
- public-safe review outcome
- contribution to DEVINES or another Being
- unresolved work carried forward
- next direction

If a cycle was missed, blocked, failed, or produced no verified progress, that becomes part of the history too.

## Evolution Law

The public Chronicle follows the same high-level evolutionary sequence as the protected system:

`OBSERVE → WORK → VERIFY → REVIEW → DISTILL → ARTIFACT / SKILL / HABIT / ABILITY → UPDATE GOALS → SLEEP`

Time awake alone is not evolution. Progress must be earned through useful work, evidence, review, and distillation.

## Public Boundary

The Chronicle never exposes credentials, private conversations, hidden reasoning, protected runtime details, exploit paths, private financial controls, or sensitive governance internals.

**The public sees the evolution. The protected core preserves what must remain private.**
